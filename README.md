# Blogging UI

A modern, responsive blogging platform UI built with **Next.js 14**, **Tailwind CSS**, and **shadcn/ui**.

## Features

- ⚡ **Next.js 14 App Router** with TypeScript
- 🎨 **Tailwind CSS** with design tokens and CSS variables
- 🧩 **shadcn/ui** core component primitives (`Button`, `Card`, `Badge`, `Input`, etc.)
- 📱 Fully responsive layout with mobile navigation and clean typography
- 🔍 Blog post search bar, categorized tags, and reading estimates

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/snhi2002-beep/blogging-ui.git
cd blogging-ui
```

2. Install dependencies:
```bash
npm install
# or
pnpm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the blog.

## Adding More shadcn/ui Components

You can add additional components using the shadcn CLI:
```bash
npx shadcn-ui@latest add <component-name>
```
